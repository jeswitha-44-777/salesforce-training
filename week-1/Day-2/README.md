# ☁️ What is Salesforce Platform?

Salesforce Platform is a cloud-based environment used to build and customize business applications.

It provides:
- apps
- objects
- automation
- security
- APIs
- development tools

---

# 📱 What is an App?

An App is a collection of related:
- tabs
- objects
- tools
- functionalities

Examples:
- Sales App
- Service App
- College Management App

Apps help users work efficiently in one environment.

---

# 📦 What is an Object?

Objects are similar to database tables.

They store information in Salesforce.

Examples:
- Account
- Contact
- Opportunity
- Student

Objects contain:
- fields
- records

---

# 🗂️ What is a Tab?

Tabs are used to access objects and features from the Salesforce UI.

Example:
Student Tab → Opens Student records.

---

# 🔄 CRM Concepts Inside Salesforce Platform

CRM concepts are implemented using objects.

Example:

| CRM Concept | Salesforce Object |
|---|---|
| Company | Account |
| Person | Contact |
| Deal/Admission | Opportunity |

These objects are organized inside apps.

---

# ⚙️ Configuration vs Coding

## Configuration (No Code)

Uses built-in Salesforce tools.

Examples:
1. Creating workflows
2. Designing page layouts

---

## Coding (Apex)

Used for advanced customization.

Examples:
1. Complex business logic
2. API integrations

---

# 🏗️ Multi-Tenant Architecture

Salesforce uses multi-tenant architecture.

Meaning:
Multiple organizations share the same platform securely.

Benefits:
- scalability
- automatic updates
- lower infrastructure cost
