# 🔹 What is Flow Builder?

Flow Builder is a Salesforce automation tool used to automate business processes without writing code.

It allows businesses to:
- Create workflows
- Update records automatically
- Send notifications
- Create tasks
- Automate repetitive actions

Flow Builder uses a visual drag-and-drop interface, making automation easier for admins and developers.

---

# 🔹 Types of Flows in Salesforce

## 1. Screen Flow
A Screen Flow interacts with users through screens and forms.

### Features
- Collects user input
- Displays screens
- Used for guided processes

### Example
Student registration form.

---

## 2. Record-Triggered Flow
A Record-Triggered Flow runs automatically when a record is created, updated, or deleted.

### Features
- Fully automated
- No user interaction needed
- Runs in background

### Example
Automatically sending email notifications after updating an account.

# 🔹 Manual vs Automated Process

## Process Chosen
Student Fee Reminder

### Manual Process
- Staff manually checks fee deadlines
- Emails students individually
- High chance of missing students

### Problems
- Time consuming
- Human errors
- Delayed communication

### Automated Process Using Salesforce
- Flow automatically checks deadlines
- Sends reminders automatically
- Ensures consistent communication

# 🔹 Reflective Questions

## Why do companies automate workflows?
To save time, reduce errors, and improve efficiency.

## What problems happen with manual processes?
Human errors, delays, inconsistency, and extra workload.

## Difference between Screen Flow and Record Triggered Flow?
Screen Flow needs user interaction, while Record Triggered Flow runs automatically.

## Why is no-code automation powerful?
It allows businesses to automate processes without programming knowledge.

## When should automation be avoided?
When human judgment or approval is important.

## How does automation improve consistency and productivity?
Tasks are completed faster and the same way every time.
